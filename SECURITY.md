# Security Policy

## Supported versions

Only the latest published version of `@jaeungkim/gantt-chart` receives fixes.

## Reporting a vulnerability

Please do not open a public issue. Report privately via
[GitHub Security Advisories](https://github.com/jaeungkim/gantt-chart/security/advisories/new).

This is a hobby project maintained by one person; expect a response within a couple of weeks.
