`GanttColumn`은 작업 목록의 열 하나를 정의해요. 헤더, 너비, 각 셀이 그리는 내용이 여기에 담겨요.
`columns` prop은 이 타입의 배열을 받아요. 타입은 패키지 루트에서 가져와요. 작업 목록 패널이 언제
나타나는지, 스플리터가 어떻게 동작하는지는 [작업 목록과 계층](../task-list)에서 다뤄요.

```tsx
import type { GanttColumn } from '@jaeungkim/gantt-chart';
```

## GanttColumn

```ts
/**
 * 왼쪽 작업 그리드의 열 하나
 *
 * 헤더 라벨과 셀 본문은 전부 여기서 나와요 - 라이브러리는 어떤 문자열도 하드코딩하지 않아요.
 * 첫 번째 열이 트리 열이라, 들여쓰기와 확장 버튼이 여기에 붙어요.
 */
export interface GanttColumn {
  /** React key이자, render가 없을 때 읽는 작업 필드 */
  key: string;
  /** 헤더에 그릴 내용 (문자열 또는 엘리먼트) */
  header: ReactNode;
  /** 열 너비, px 단위 (기본값 120) */
  width?: number;
  /** 셀 렌더러 - 없으면 task[key]가 문자열로 표시돼요 */
  render?: (task: TaskTransformed) => ReactNode;
}
```

| 필드 | 타입 | 필수 | 기본값 | 의미 |
|---|---|---|---|---|
| `key` | `string` | 예 | — | 헤더 셀과 본문 셀의 React key, 그리고 `render`가 없을 때 읽는 `TaskTransformed` 필드 |
| `header` | `ReactNode` | 예 | — | 헤더 셀 내용 |
| `width` | `number` | 아니요 | `120` | 열 너비, px 단위 |
| `render` | `(task: TaskTransformed) => ReactNode` | 아니요 | — | 작업 하나의 셀 내용 |

`render`는 원본 `Task`가 아니라 [`TaskTransformed`](task)를 받아요. 그래서 파생 필드인
`barLeft`, `barWidth`, `depth`, `order`, `originalOrder`, `isSummary`를 바로 쓸 수 있어요.
임계 경로(critical path) 필드인 `earlyStart`, `earlyFinish`, `lateStart`, `lateFinish`,
`totalSlack`, `freeSlack`, `critical`, `duration`은 `criticalPath` prop이 켜져 있을 때만 행에
기록돼요. 꺼져 있으면 `undefined`라, 그 필드를 `key`로 삼은 열은 빈 셀을 그려요.

## 기본 열

`showTaskList`가 켜져 있고 `columns` 배열이 없으면, 차트는 이 세 개를 그려요.

| # | `key` | `header` | `width` | 셀 내용 |
|---|---|---|---:|---|
| 0 | `name` | `Name` | `220` | `render` 없음 → `String(task.name)` |
| 1 | `startDate` | `Start` | `110` | `dayjs(task.startDate).format('YYYY-MM-DD')` |
| 2 | `endDate` | `End` | `110` | `dayjs(task.endDate).format('YYYY-MM-DD')` |

너비 합은 `440`이고, 이 경우 그 값이 패널의 초기 너비가 돼요.

이 배열은 내부용이에요. 패키지에서 export하지 않으니 import도, 전개도, 확장도 못 해요. `columns`를
넘기면 통째로 교체돼요. `'YYYY-MM-DD'` 날짜 형식도 마찬가지로 모듈 내부에만 있어요. 바꾸려면
`render`를 담은 `startDate` / `endDate` 열을 직접 넘겨야 해요.

## `render` 없는 셀 렌더링

```ts
/** render가 없으면 task[key]가 그대로 표시돼요 */
function renderCell(column: GanttColumn, task: TaskTransformed): ReactNode {
  if (column.render) return column.render(task);

  const value = (task as unknown as Record<string, unknown>)[column.key];
  return value == null ? "" : String(value);
}
```

| `task[key]` | 셀에 표시되는 값 |
|---|---|
| `null` 또는 `undefined` | `""` |
| `false` | `"false"` |
| `0` | `"0"` |
| 배열 | 쉼표로 이어붙인 문자열 |
| 객체 | `"[object Object]"` |
| 그 밖의 값 | `String(value)` |

`TaskTransformed`의 어떤 필드와도 맞지 않는 `key`는 예외를 던지지 않고 빈 셀을 그려요.

## 첫 번째 열

배열의 인덱스 0이 트리 열이에요. 차트는 이 열에만 다음을 붙여요.

- `depth` 단계마다 `16px`씩 커지는 들여쓰기 여백,
- 요약 행이나 그룹 헤더의 확장 버튼 (나머지 행에는 `20px` 여백),
- 행에 작업이 둘 이상일 때 붙는 `+N` 배지 (`N`은 `row.tasks.length - 1`),
- 열이 무엇을 그리든 항상 `task.name`을 보여주는 네이티브 `title` 툴팁.

너비를 정하는 방식도 인덱스 0만 달라요.

```ts
/** 첫 번째 열은 트리 열이에요 - 남는 너비를 가져가고, 나머지는 자기 너비를 지켜요 */
function cellStyle(column: GanttColumn, index: number) {
  const width = column.width ?? DEFAULT_COLUMN_WIDTH;
  return index === 0
    ? { flex: `1 1 ${width}px`, minWidth: 60 }
    : { flex: `0 0 ${width}px` };
}
```

| 인덱스 | Flex | 패널 크기를 바꿀 때 |
|---|---|---|
| `0` | `1 1 <width>px`, `min-width: 60` | 스플리터가 더하거나 빼는 px를 모두 흡수하고, `60`까지 줄어들어요 |
| `1..n` | `0 0 <width>px` | 고정이라 늘지도 줄지도 않아요 |

`DEFAULT_COLUMN_WIDTH`는 `120`이고 패키지에서 export하지 않아요. 헤더 셀에도 같은 `cellStyle`이
적용되니 헤더와 본문이 어긋나지 않아요.

## 예제

```tsx
// TaskListColumns.tsx
import { ReactGanttChart } from '@jaeungkim/gantt-chart';
import type { GanttColumn, Task } from '@jaeungkim/gantt-chart';

const columns: GanttColumn[] = [
  { key: 'name', header: 'Task', width: 240 },
  { key: 'depth', header: 'Level', width: 80 },
  {
    key: 'progress',
    header: 'Done',
    width: 90,
    render: (task) => `${task.progress ?? 0}%`,
  },
];

const tasks: Task[] = [
  {
    id: 'design',
    name: 'Design',
    startDate: '2026-01-05',
    endDate: '2026-01-09',
    parentId: null,
    sequence: '1',
    progress: 100,
  },
  {
    id: 'build',
    name: 'Build',
    startDate: '2026-01-12',
    endDate: '2026-01-23',
    parentId: null,
    sequence: '2',
    progress: 40,
  },
];

export default function TaskListColumns() {
  return <ReactGanttChart tasks={tasks} columns={columns} />;
}
```

`depth`에는 `render`가 없어요. `TaskTransformed`에서 읽어 문자열로 바꿔 보여줘요. `progress`에는
`render`가 있어서 셀에 `40` 대신 `40%`가 나와요.

## 제약

- 그룹 헤더 행은 `columns`를 아예 무시해요. 그룹으로 묶인 행 밴드는 확장 버튼, 그룹 라벨,
  작업 개수를 담은 전체 너비 셀 하나를 그려요.
- 열은 가상화되지 않아요. 보이는 행마다 모든 항목이 렌더링되니, 열이 30개인 작업 목록은 행마다
  셀 30개를 써요.
- 패널 너비는 마운트 시점에 열 너비로 한 번만 계산돼요. 그 뒤에 `columns`를 바꿔도 패널 크기는
  그대로예요. 스플리터는 합계와 무관하게 `120`–`800` px로 제한해요.
- 열 크기 조절, 순서 변경, 숨기기, 고정, 정렬, 필터링은 없어요. `width`는 렌더 시점에 고정되고,
  배열은 준 순서대로 그려져요.
- `key` 값이 중복되면 React 중복 key 경고가 떠요. `key`는 헤더 셀과 본문 셀을 함께 식별하니까요.
- 패널이 보이지 않으면 `columns`는 아무 일도 하지 않아요. `columns` 배열을 넘겼더라도
  `showTaskList={false}`를 명시하면 그쪽이 이겨요. [`GanttProps`](props)를 참고해요.
