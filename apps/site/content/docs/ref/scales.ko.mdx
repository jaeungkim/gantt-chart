타임라인을 어떻게 재고 차트를 어떻게 칠할지는 네 가지 타입이 정해요. `GanttScaleKey`는 다섯 가지
배율 중 하나를 가리키고, `GanttScaleFormat`과 `GanttFormatOverrides`는 한 배율의 라벨을 바꿔요.
`GanttTheme`은 팔레트를 골라요. 네 타입 모두 패키지 루트에서 내보내요.

```tsx
import type {
  GanttScaleKey,
  GanttScaleFormat,
  GanttFormatOverrides,
  GanttTheme,
} from '@jaeungkim/gantt-chart';
```

## GanttScaleKey

```ts
export type GanttScaleKey = 'day' | 'week' | 'month' | 'quarter' | 'year';
```

선언 순서가 사다리예요. 가장 촘촘한 배율이 먼저 와요. Ctrl/Cmd + ArrowUp은 한 칸 촘촘하게,
Ctrl/Cmd + ArrowDown은 한 칸 성기게 옮기고, 양쪽 끝에서 멈춰요. `zoomOnWheel`을 켜면 Ctrl/Cmd + 휠도
같은 사다리를 걸어요. `defaultScale`은 이 값 중 하나를 받고, 기본값은 `'month'`예요.

차트는 배율 선택기를 그리지 않고, 다시 마운트하면 배율도 기억하지 않아요. 선택기가 필요하면 호스트가 직접
그리고, ref의 `setScale`으로 배율을 바꾸고, 휠과 키보드까지 포함한 모든 변경을 `onScaleChange`로
따라가요. [GanttHandle](handle)을 참고해 주세요.

이 키는 다른 여러 곳에도 나와요. `formats`가 이 키로 묶이고,
`GanttTooltipRenderProps.scale`, `GanttHeaderCellRenderProps.scale`이 이 값을 담아요.
[렌더러](renderers)를 참고해 주세요.

### 배율별 설정

키 하나는 고정된 표의 한 행에 대응해요. 그 행이 헤더 셀에 무엇을 쓸지, 눈금 하나가 얼마만큼의 시간을
덮을지, 드래그 한 단계가 몇 픽셀인지를 정해요.

| 배율 | `labelUnit` | `tickUnit` | `unitPerTick` | `tickAlign` | `dragStepUnit` | `dragStepAmount` | `basePxPerDragStep` |
|---|---|---|---:|---|---|---:|---:|
| `day` | `day` | `hour` | 6 | `day` | `hour` | 1 | 12 |
| `week` | `month` | `day` | 1 | — | `hour` | 6 | 18 |
| `month` | `month` | `day` | 7 | `week` | `day` | 1 | 18 |
| `quarter` | `quarter` | `month` | 1 | — | `day` | 7 | 28 |
| `year` | `year` | `month` | 3 | `quarter` | `day` | 28 | 28 |

한 행의 생김새는 이래요.

```ts
export interface GanttScaleConfig {
  labelUnit: GanttLabelUnit;
  tickUnit: 'minute' | 'hour' | 'day' | 'week' | 'month';
  unitPerTick: number;
  /** Boundary the first cell snaps to, when a cell holds more than one tickUnit */
  tickAlign?: GanttLabelUnit;

  dragStepUnit: 'minute' | 'hour' | 'day' | 'week';
  dragStepAmount: number;

  basePxPerDragStep: number;

  formatTickLabel?: (date: Dayjs) => string;
  formatHeaderLabel?: (date: Dayjs) => string;
}
```

```ts
/** 상단 헤더 행이 묶는 단위 ('quarter'는 dayjs에 대응하는 단위가 없어요 - core/dates 참고) */
export type GanttLabelUnit =
  | 'hour'
  | 'day'
  | 'week'
  | 'month'
  | 'quarter'
  | 'year';
```

`GanttScaleConfig`와 `GanttLabelUnit`, 그리고 `GANTT_SCALE_CONFIG` 객체 자체는 **패키지에서
내보내지 않아요**. 모듈 내부에만 있어요. 위 표는 가져오거나 확장하거나 교체할 수 없고, 여섯 번째 배율을
추가하는 prop도 없어요. 눈금 너비는 `basePxPerDragStep / dragStepAmount`에서 나와요. 그 계산은
[타임라인](../timeline)에서, 같은 두 필드가 정하는 드래그 격자는 [작업 편집](../editing)에서
다뤄요.

### 기본 라벨

`formatTickLabel`과 `formatHeaderLabel`은 라벨 체인의 마지막 층이에요. `formats` 재정의도 없고
`locale`도 적용되지 않을 때 그려지는 값이에요.

| 배율 | `formatTickLabel` | `formatHeaderLabel` | 툴팁 포맷 문자열 | readout 포맷 문자열 |
|---|---|---|---|---|
| `day` | `d.format('HH')` | `d.format('MMM D, YYYY')` | `'MMM D, YYYY HH:mm [UTC]'` | `'MMM D, HH:mm [UTC]'` |
| `week` | `d.format('D')` | `d.format('MMM YYYY')` | `'MMM D, YYYY'` | `'MMM D'` |
| `month` | `d.format('MMM D')` | `d.format('MMM YYYY')` | `'MMM D, YYYY'` | `'MMM D'` |
| `quarter` | `d.format('MMM')` | `` `Q${quarterOfYear(d)} ${d.format('YYYY')}` `` | `'MMM YYYY'` | `'MMM YYYY'` |
| `year` | `d.format('MMM')` | `d.format('YYYY')` | `'MMM YYYY'` | `'MMM YYYY'` |

툴팁과 readout 문자열은 각각 `DATE_FORMATS`와 `RANGE_FORMATS` 상수에 있고, 둘 다 내보내지 않아요.
hour와 day 문자열에 들어간 `[UTC]`는 dayjs가 이스케이프한 리터럴이에요. 해석된 시간대 이름이
아니에요. readout은 드래그 중인 구간의 양 끝을 그린 뒤 en dash로 이어요. 양 끝이 똑같이 그려지면
라벨 하나만 찍어요. 더 짧은 문자열이 연도를 빼는 건 readout 바로 위의 헤더 행이 이미 연도를 보여
주기 때문이에요. `quarter`와 `year`는 연도를 남겨요. 그 배율에서는 구간이 해를 넘길 수 있거든요.

## GanttScaleFormat

```ts
/**
 * 한 배율에서 생성된 라벨을 대체해요
 * 모든 항목은 선택이에요 - 빼놓은 항목은 기본 라벨(또는 locale 라벨)을 그대로 써요
 */
export interface GanttScaleFormat {
  /** 하단 헤더 행 - 눈금마다 라벨 하나 */
  tick?: (date: Dayjs) => string;
  /** 상단 헤더 행 - 그룹마다 라벨 하나 */
  header?: (date: Dayjs) => string;
  /** 헤더 드래그 readout과 막대의 스크린 리더 드래그 안내 */
  tooltip?: (date: Dayjs) => string;
}
```

| 필드 | 타입 | 필수 | 적용 대상 |
|---|---|---|---|
| `tick` | `(date: Dayjs) => string` | 아니요 | 눈금마다 라벨 하나, 하단 헤더 행 |
| `header` | `(date: Dayjs) => string` | 아니요 | 그룹마다 라벨 하나, 상단 헤더 행 |
| `tooltip` | `(date: Dayjs) => string` | 아니요 | 헤더 드래그 readout과 막대의 스크린 리더 드래그 안내 |

셋은 서로 따로 결정돼요. 그래서 `header`만 넘기면 `tick`과 `tooltip`은 `locale`이나 기본 라벨이 만든
값 그대로 남아요.

## GanttFormatOverrides

```ts
/** 배율별 라벨 재정의, 예: `{ quarter: { header: (d) => ... } }` */
export type GanttFormatOverrides = Partial<
  Record<GanttScaleKey, GanttScaleFormat>
>;
```

`formats` prop의 타입이 이거예요. 레코드에서 빠진 배율은 결정된 라벨을 그대로 유지해요.

```tsx title="QuarterHeader.tsx"
import { ReactGanttChart } from '@jaeungkim/gantt-chart';
import type { GanttFormatOverrides, Task } from '@jaeungkim/gantt-chart';

const formats: GanttFormatOverrides = {
  quarter: {
    header: (d) => `${d.year()} Q${Math.floor(d.month() / 3) + 1}`,
  },
  month: {
    tooltip: (d) => d.format('YYYY-MM-DD'),
  },
};

const tasks: Task[] = [
  {
    id: 'design',
    name: 'Design',
    startDate: '2026-01-05',
    endDate: '2026-02-20',
    parentId: null,
    sequence: '1',
  },
];

export default function QuarterHeader() {
  return <ReactGanttChart tasks={tasks} formats={formats} locale="en-US" />;
}
```

여기서 `formats`를 모듈 스코프에 선언한 건 의도한 거예요. 아래 객체 식별자 항목을 참고해 주세요.

세 라벨 각각에서 어느 층이 이기는지는 [로케일과 날짜 형식](../i18n)에 정리돼 있어요.

## GanttTheme

```ts
/** 차트 테마 - 'light'와 'dark'는 명시적이고 'system'은 OS 설정을 따라요.
 *  생략하면 호스트 페이지의 `color-scheme`을 따라가요. */
export type GanttTheme = 'light' | 'dark' | 'system';
```

`theme` prop의 타입이 이거고, 기본값은 없어요. 어떤 값으로 풀리든 컨테이너의 `data-theme`에 쓰이고,
스타일시트가 읽는 것도 그 속성이에요. 값마다 어떻게 풀리는지와 그 뒤의 팔레트는
[테마](../theming)에 있어요.

테마 객체도 없고 토큰 prop도 없어요. `GanttTheme`은 값이 셋인 유니온이고, 모든 색은 CSS 커스텀
속성이에요.

## 참고

- **`tick`과 `header`, `tooltip` 함수에 넘어오는 `Dayjs`는 모두 `dayjs.utc()` 인스턴스예요.**
  차트는 모든 날짜를 UTC로 파싱하고 배치하고 라벨링해요. 그래서 재정의 안에서 `d.format('HH:mm')`과
  `d.year()`, `d.month()`, `d.day()`는 보는 사람의 로컬 시각이 아니라 UTC 벽시계 값을 읽어요. 로컬
  시간으로 바꾸는 포매터는 자기가 놓인 셀과 어긋나는 라벨을 찍어요.
- `header`는 처음 보이는 셀의 날짜가 아니라 **그룹의 시작 날짜**를 받아요. 월요일부터 묶는 week 배율에서
  처음 그려지는 셀이 `2025-08-31`인 그룹은 `2025-08-25T00:00:00Z`로 라벨이 붙어요.
- `formats`는 파생 단위가 아니라 지금 그려지는 배율로 묶여요. `firstDayOfWeek`를 지정한 `week` 배율에서는
  헤더를 day 배율 옵션으로 만들지만, 재정의는 여전히 `formats.week.header`에서 읽어요. 거기서
  `formats.day.header`는 아무 일도 하지 않아요.
- `formats` 객체는 메모이즈하거나 모듈 스코프에 둬야 해요. 렌더마다 객체 식별자가 새로 생기면 라벨 메모가
  무효화돼요. `locale`까지 함께 지정했다면 `Intl.DateTimeFormat` 인스턴스도 전부 다시 만들어요. 경고는
  뜨지 않아요.
- `GanttScaleFormat` 함수는 `string`을 반환해야 해요. 여기에는 `ReactNode` 탈출구가 없어요. 헤더 셀에
  마크업을 그리려면 `renderHeaderCell`을 써요([렌더러](renderers)).
- 상단 행에서 서로 이웃한 그룹이 **같은 문자열**로 포맷되면 한 셀로 합쳐져요. 상수를 반환하는 `header`
  재정의는 상단 행 전체를 하나로 접어 버려요.
- 차트가 쓰는 UTC `dayjs` 인스턴스는 패키지에서 내보내지 않아요. 재정의에서 같은 인스턴스가 필요하면
  `dayjs`와 `utc` 플러그인을 직접 불러와요.
