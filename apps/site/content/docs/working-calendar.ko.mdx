`workingCalendar`는 막대 드래그 결과를 주말과 휴일 다음 근무일로 미는 prop이에요. 이 페이지는
이 prop과 제스처별 스냅, 바뀌지 않는 동작, 한계를 다뤄요.

## 근무일 달력

`workingCalendar`는 불리언이고 기본값은 `false`예요. 켜면 차트가 비근무일을 건너뛰는 달력을 만들어서
막대 드래그에 넘겨요. 끄면 모든 날을 세는 달력을 써서 일반 달력 산술로 계산해요.

```tsx title="src/WorkWeek.tsx"
import { ReactGanttChart, type Task } from '@jaeungkim/gantt-chart';
import '@jaeungkim/gantt-chart/style.css';

export function WorkWeek({ tasks, setTasks }: {
  tasks: Task[];
  setTasks: (next: Task[]) => void;
}) {
  return (
    <ReactGanttChart
      tasks={tasks}
      onTasksChange={setTasks}
      workingCalendar
      holidays={['2026-09-21']}
    />
  );
}
```

prop을 켜면 음영과 스냅이 같은 달력 객체를 써요. `workingWeekdays`에 그 요일이 없거나 `holidays`에
그날의 UTC `YYYY-MM-DD`가 있으면 비근무일이에요.

음영이 들어가는 날과 건너뛰는 날은 이 정의 하나를 함께 써서 항상 같아요. 두 prop과 음영은
[타임라인](timeline)에서 설명해요.

휴일의 `label`과 `color`는 스냅에 영향을 주지 않아요. 스냅은 하루가 근무일인지만 읽어서 이름 붙은
휴일이든 토요일이든 같은 일수만큼 드롭을 밀어요.

차트는 직접 만든 달력을 받지 않아요. `workingWeekdays`와 `holidays`가 달력을 설명해요.
`WorkingCalendar` 객체를 받는 prop은 없어요.

격주 금요일 휴무나 사람마다 다른 달력처럼 두 prop으로 표현할 수 없는 규칙에는 스냅이 적용되지
않아요. 호스트 앱의 날짜 계산에는 [근무일 달력 헬퍼](ref/core-calendar)의 `createWorkingCalendar`를
쓰세요.

prop과 기본값은 [GanttProps](ref/props)를 참고하세요.

### 드롭 스냅

스냅은 달력이 제스처에 하는 일이에요. 드래그의 나머지 동작은 그대로예요.

드래그한 쪽 끝이 근무일에 놓여요. 함께 움직이는 나머지 끝은 같은 일수만큼 따라와요. 요약 막대는
하위 트리 전체가 함께 움직여요.

요약 막대는 [작업 목록과 계층](task-list)에서 설명해요.

| 제스처 | 스냅하는 끝 | 반대쪽 끝 |
|---|---|---|
| 이동 | 시작 | 같은 일수만큼 따라와서 구간이 유지돼요 |
| 왼쪽 크기 조절 | 시작 | 그대로 남아서 막대가 짧아져요 |
| 오른쪽 크기 조절 | 끝 | 그대로 남아서 막대가 길어져요 |

스냅은 하루 단위로 계산하고 앞으로만 움직여요. 그래서 하루 중 시각은 그대로 남아요. 막대의 끝을
넘어가는 왼쪽 끝 크기 조절은 스냅하지 않아요.

스냅은 드래그 중에 적용돼요. 포인터가 눌려 있는 동안 막대와 눈금 행의 드래그 날짜 표시가 이미 스냅된
날짜를 보여줘요. 손을 떼면 그 날짜가 그대로 확정돼요.

### 그대로 유지되는 동작

막대를 그리는 위치와 폭은 달력과 무관해요. 주말을 가로지르는 막대는 화면에서 그대로 주말을
가로질러요. 달력은 드롭이 놓일 날짜만 정하기 때문이에요.

타임라인 눈금과 헤더 셀도 바뀌지 않아요. 음영도 바뀌지 않아요. 음영은 전용 prop으로 따로 조절해요.

드래그 자체는 일반 달력 시간으로 움직여요. 포인터 위치를 날짜로 바꾸는 계산은 모든 날을 세는
방식이에요.

달력은 그 결과에 앞으로 미는 스냅만 더해요. 그래서 이동은 막대 구간을 근무일이 아니라 달력 기준
일수로 유지해요.

## 예제로 확인하기

이 예제는 작업 하나만 써요. 시각은 모두 UTC예요. `workingCalendar`는 켜져 있고 휴일은 없어요.

```ts
import type { Task } from '@jaeungkim/gantt-chart';

export const tasks: Task[] = [
  {
    id: 'audit', name: 'Content audit', parentId: null, sequence: '1',
    startDate: '2026-09-01T09:00:00Z', endDate: '2026-09-04T17:00:00Z',
  },
];
```

`09-01`은 화요일이고 `09-04`는 금요일이라 막대가 같은 주 근무일 안에 들어가요. 월 배율에서는
드래그 한 단계가 하루예요. 이 배율에서 끌어 보세요.

| 제스처 | `workingCalendar` 없이 | 켰을 때 |
|---|---|---|
| 3일 뒤로 이동 | `09-04 09:00 - 09-07 17:00` | 그대로예요. 금요일은 근무일이에요 |
| 4일 뒤로 이동 | `09-05 09:00 - 09-08 17:00` | `09-07 09:00 - 09-10 17:00` |
| 오른쪽 끝을 1일 뒤로 | `09-01 09:00 - 09-05 17:00` | `09-01 09:00 - 09-07 17:00` |

4일 뒤로 이동하면 시작이 토요일이 돼요. 그래서 시작이 2일 밀려 월요일로 가고 끝도 2일 따라와요.
막대의 3일 구간은 그대로 유지돼요.

오른쪽 크기 조절은 끝만 토요일에서 월요일로 스냅해서 막대가 드래그 위치보다 2일 늦게 끝나요.

`holidays={['2026-09-07']}`를 더하면 4일 이동이 하루 더 밀려서 시작은 `09-08 09:00`, 끝은
`09-11 17:00`이 돼요.

## 한계

스냅은 포인터로 막대를 드래그할 때만 실행돼요. 새 `tasks` 배열을 불러오거나 링크를 그리거나 마지막
행 아래에 새 작업을 그릴 때는 넘긴 날짜가 그대로 남아요. [상세 패널](detail-panel)에서 날짜 필드를
고칠 때도 그대로예요.

키보드 편집도 스냅하지 않아요. `Alt` + 방향키 이동과 키보드 크기 조절은 드래그 단계 그대로 움직여서
막대가 비근무일에 남을 수 있어요. 키 바인딩은
[키보드와 스크린 리더](accessibility)를 참고하세요.

`minDate`와 `maxDate` 범위 제한은 스냅 다음에 실행돼요. 제한이 우선이라 경계에 고정된 막대는
토요일에 끝날 수 있어요. 이 경계는 [작업 편집](editing)에서 설명해요.

근무일 달력은 차트에서 편집할 수 없어요. 호스트 앱이 넘기는 데이터예요.
