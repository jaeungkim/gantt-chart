Use `@jaeungkim/gantt-chart` to build an editable project schedule or release roadmap in React.
It provides the timeline and editing interactions; your app supplies the task data and saves changes.

## What you can build

Users can drag tasks to new dates, edit progress in a detail panel, and connect tasks with dependency arrows.
Group work into project phases with [hierarchy](task-list), or place multiple bars on a row with [lanes](lanes).

The chart includes five timeline scales, working-day shading, optional working-calendar snapping,
light and dark themes, and adjustable row and bar heights.
Rows and time cells are virtualized to limit how much is rendered at once.

Try these features in the [playground](/playground), or follow [Quick start](quick-start)
to add the chart to your app.

## How it fits into your app

Pass your tasks to the chart and receive edits through `onTasksChange`.
The callback gives you the updated task array, which you can keep in React state.
[Events and saving](events) shows how to connect this to your application.

The chart keeps temporary interaction state while it is mounted.
It does not save data to a server or browser storage.
Your app handles loading, saving, validation and any collaboration or undo workflow.

You also choose the controls around the chart.
Use the [ref API](imperative-api) for a scale picker, a Today button or navigation to a task.
Use the [detail panel](detail-panel) for editing task fields.

## Check the fit

The package supports React 18 and 19 and includes TypeScript types.
It is MIT licensed and can be used in commercial projects.

Consider these boundaries when planning an integration:

- Dependencies show relationships; moving a predecessor does not automatically reschedule successors.
  See [Dependencies](dependencies).
- Lanes group bars visually. Resource allocation, workload balancing and cost calculations are not included.
- There is no built-in PDF, image or spreadsheet export, or dedicated print layout.
- Date labels can be localized. Built-in interface text remains English, and RTL layout is not supported.
  See [Locale and date formats](i18n).
- Bars and rows take no keyboard focus, and every drag needs a pointer.
  The chart sets no ARIA roles and makes no screen reader announcements.
  The task list's grip and expander buttons, the detail panel's name field and close button, and the link menu's delete button carry English `aria-label`s.

For data operations outside the chart, the package also exports [tree and calendar helpers](headless-core).
