`@jaeungkim/gantt-chart`로 React 앱에 직접 편집할 수 있는 프로젝트 타임라인을 추가하세요.
동작하는 예제로 시작한 뒤 필요한 기능을 하나씩 붙일 수 있어요.

## 여기서 시작하세요

1. **[빠른 시작](quick-start):** 패키지를 설치하고 편집 가능한 차트를 만들어요.
2. **[작업 데이터](task-data):** 앱의 데이터를 차트의 작업 형식에 맞춰요.
3. **[이벤트와 저장](events):** 편집 결과를 상태에 반영하고 앱의 API로 저장해요.

먼저 사용해 보고 싶다면 [플레이그라운드](/ko/playground)를 열어 보세요.
지원 범위는 [소개](introduction), 낯선 용어는 [개념](concepts)에서 확인할 수 있어요.

## 필요한 기능을 추가하세요

가이드마다 기능 하나를 다뤄요.

- **[작업 목록과 계층](task-list):** 작업을 프로젝트 단계로 묶어요.
- **[레인](lanes):** 여러 작업을 한 행에 배치해요.
- **[작업 편집](editing):** 날짜와 진행률을 바꿔요.
- **[작업 생성](task-creation):** 사용자가 작업을 추가할 수 있게 해요.
- **[행 순서 바꾸기](reordering):** 순서를 바꾸거나 다른 단계로 작업을 옮겨요.
- **[의존성](dependencies):** 작업 사이에 연결을 만들어요.
- **[근무일 달력](working-calendar):** 드래그할 때 주말과 휴일을 건너뛰어요.
- **[상세 패널](detail-panel):** 차트 옆에 작업 편집기를 붙여요.
- **[차트 컨트롤](imperative-api):** 배율과 이동 컨트롤을 추가해요.
- **[테마](theming)와 [스타일링](styling):** 앱 디자인에 맞춰요.
- **[로케일과 날짜 형식](i18n):** 다른 언어로 날짜를 표시해요.

## API를 찾아보세요

컴포넌트 prop은 [GanttProps](ref/props), 작업 필드는 [Task](ref/task),
ref로 호출하는 메서드는 [GanttHandle](ref/handle)에 정리돼 있어요.
