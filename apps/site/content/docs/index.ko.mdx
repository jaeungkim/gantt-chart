`@jaeungkim/gantt-chart`는 제어 컴포넌트처럼 동작하는 React 간트 차트예요. `tasks` 배열은 앱이
들고 있고 편집이 확정될 때마다 다음 배열 전체가 `onTasksChange`로 돌아와요.

다른 React 간트 컴포넌트와 구분되는 점은 세 가지예요.

- 이동과 크기 조절, 순서 바꾸기, 삭제를 하나의 ARIA `treegrid` 안에서 키보드로 할 수 있어요. 편집
  결과는 `role="status"` 요소로 알려요. 의존성 화살표를 그리는 키보드 경로는 없어요.
  [키보드와 스크린 리더](accessibility) 참고
- 행과 시간 열은 하나의 스크롤 컨테이너를 기준으로 가상화되고 막대와 화살표도 같은 범위로
  걸러져요. [소개](introduction) 참고
- 트리와 달력 계산은 React와 DOM이 없는 헤드리스 코어예요. `src/core`에만 걸린 eslint
  `no-restricted-imports` 블록이 이 경계를 강제해요. [헤드리스 코어](headless-core) 참고

[빠른 시작](quick-start)부터 시작하세요. 모든 prop은 [GanttProps](ref/props)에 있어요.
