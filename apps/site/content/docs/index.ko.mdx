React 앱 안에서 직접 편집할 수 있는 프로젝트 일정을 만드세요. `@jaeungkim/gantt-chart`는
작업 드래그와 의존성 연결, 계층형 타임라인을 하나의 MIT 라이선스 컴포넌트로 제공해요.

만들려는 기능에 맞는 가이드를 골라 보세요.

- 타임라인에서 날짜와 진행률 바꾸기: [작업 편집](editing)
- 프로젝트 단계를 정리하고 하위 작업을 함께 옮기기: [작업 목록과 계층](task-list)
- 의존성 화살표로 작업 연결하기: [의존성](dependencies)
- 근무 요일과 휴일 반영하기: [근무일 달력](working-calendar)
- 제품에 맞게 디자인 조절하기: [테마](theming)
- 키보드로 편집하기: [키보드와 스크린 리더](accessibility)

앱은 `onTasksChange`로 변경된 작업 데이터를 받아요.
연동 방식은 [이벤트](events), 지원 범위와 한계는 [소개](introduction)에서 확인하세요.

[빠른 시작](quick-start)부터 시작하세요. 모든 prop은 [GanttProps](ref/props)에 있어요.
