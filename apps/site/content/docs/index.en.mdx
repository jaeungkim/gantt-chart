`@jaeungkim/gantt-chart` is a Gantt chart for React that behaves like a controlled input. Your app
holds the `tasks` array, and every committed edit returns the complete next array through
`onTasksChange`.

Three things separate it from other React Gantt components.

- Move, resize, reorder and delete run from the keyboard inside one ARIA `treegrid`, and each edit
  is announced in a `role="status"` region. Drawing a dependency arrow has no keyboard path. See
  [Keyboard and screen readers](accessibility).
- Rows and time columns are virtualized against one scroll container, and the bars and the arrows
  cull against the same window. See [Introduction](introduction).
- The tree and calendar math is a headless core with no React and no DOM, enforced by an eslint
  `no-restricted-imports` block scoped to `src/core`. See [Headless core](headless-core).

Start at [Quick start](quick-start). Every prop is listed in [GanttProps](ref/props).
