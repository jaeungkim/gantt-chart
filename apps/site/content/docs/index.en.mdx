Add an interactive project timeline to your React app with `@jaeungkim/gantt-chart`.
Start with a working example, then add the features your project needs.

## Start here

1. **[Quick start](quick-start):** Install the package and render an editable chart.
2. **[Task data](task-data):** Map your application's data to tasks.
3. **[Events and saving](events):** Keep edits in state and save them through your API.

Want to try it first? Open the [playground](/playground).
Read [Introduction](introduction) for the package's scope and [Concepts](concepts) when a term is unfamiliar.

## Build your workflow

Each guide covers one feature.

- **[Task list and hierarchy](task-list):** Group tasks into project phases.
- **[Lanes](lanes):** Put multiple tasks on one row.
- **[Editing tasks](editing):** Change dates and progress.
- **[Creating tasks](task-creation):** Let users add tasks.
- **[Reordering rows](reordering):** Change row order or move tasks between phases.
- **[Dependencies](dependencies):** Connect tasks.
- **[Working calendar](working-calendar):** Skip weekends and holidays when dragging.
- **[Detail panel](detail-panel):** Add a task editor beside the chart.
- **[Chart controls](imperative-api):** Add zoom and navigation controls.
- **[Theming](theming) and [Styling](styling):** Match your app's design.
- **[Locale and date formats](i18n):** Format dates for another language.

## Look up an API

Use [GanttProps](ref/props) for component props, [Task](ref/task) for task fields,
and [GanttHandle](ref/handle) for methods called through a ref.
