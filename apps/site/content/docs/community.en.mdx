You can help improve the project by sharing how you use it, reporting a problem,
or making a small improvement to the code or docs.

## Ask a question

Use [GitHub Discussions](https://github.com/jaeungkim/gantt-chart/discussions)
for integration questions and feature ideas.
Include what you are trying to build and the part you are unsure about.

## Report a bug

Open an [issue](https://github.com/jaeungkim/gantt-chart/issues) with:

- The package version and your React version.
- A small task array and the relevant chart props.
- Steps to reproduce, what you expected, and what happened.
- Your browser and input method when the problem involves dragging or keyboard use.

A minimal reproduction is especially helpful.
If the problem happens in the playground, include its URL with your settings.

## Make a contribution

Documentation fixes, clearer examples and focused bug fixes are good places to start.
For a larger change, discuss the approach first so the scope is clear.

The repository's [contributing guide](https://github.com/jaeungkim/gantt-chart/blob/main/CONTRIBUTING.md)
covers local setup, development and required checks.
English and Korean docs are maintained together; update both when changing a page.

## Follow releases

Read [GitHub Releases](https://github.com/jaeungkim/gantt-chart/releases)
for published versions and release notes.
